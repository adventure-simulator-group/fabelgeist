# Encrypted supplemental process evidence, additive successor

Run `python3 -B VERIFY.py` for ciphertext identities. Supply the separately
held primary key and a new `--restore-root` to authenticate and restore.
The first 46 ciphertext objects are identical to the preserved predecessor;
two new objects add the primary receipt-scan subtree and checksum-pinned
archive replicas. Their private registration records original file names and
versions. The encrypted supplemental-control object holds the earlier source
map and scope qualifications.

The other large restored/public trees remain separate primary-ciphertext and
public-archive dependencies. Git objects, q2812 anchors, nested keys and
earlier ciphertext also remain separate. Archive ownership and timestamps are
normalized. This is same-machine custody, not independent recovery, checkpoint
3821 restoration, product validation or audit closure. Ciphertext is opaque to
public privacy scans.
