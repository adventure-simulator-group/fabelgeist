# Guard-v4 static peer review

These archives preserve an independent static comparison and public replay
of the unrun v4 evidence guard draft. Its fixed stage snapshot predates later
source transports and custody groups. The privacy driver matched at review
time but v4 itself did not pin it. Git file executable bits, full POSIX and
directory modes, optional predecessor routing and deeper history remain
separate qualifications.

Run `python3 -B VERIFY.py` for archive and original-manifest identities.
Restricted originals, historical Git objects and the same-machine key remain
separate. No independent custody, semantic closure or product behavior
is established.
