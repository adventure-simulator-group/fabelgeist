# Private packet privacy limits

This exact packet contains local paths and must not be published unredacted. A
bounded prescan covered 123 then-existing files and 113 distinct raw or
decoded views, with 270 local/audit path-pattern occurrences and three broader
pattern candidates across 79 distinct candidate values. Two broad candidates
are the same canonical agent identifier and one is Python code-token text;
none is an additional filesystem path. The supplement preserves reviewer
attribution when a public reconstruction redacts those strings. No email or
credential-pattern matches and no path matches in decoded views were found.
External anchors, Git history, unknown encodings and unrecognized secrets
were excluded. See the counts-only prescan and candidate classification.
