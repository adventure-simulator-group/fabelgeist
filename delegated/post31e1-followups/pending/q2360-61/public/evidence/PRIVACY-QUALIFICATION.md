# Private packet privacy limits

This exact packet contains local paths and must not be published unredacted.
A bounded prescan covered 144 then-existing files and 135 distinct raw or
decoded views. It found 316 local/audit path-pattern occurrences and one
additional broad pattern candidate across 111 distinct candidate values; the
extra candidate is code-token text, not an actual local path. No email or
credential-pattern matches and no path matches in decoded views were found.
External anchors, Git history, unknown encodings and unrecognized secrets
were excluded. See the counts-only receipt and candidate classification.
