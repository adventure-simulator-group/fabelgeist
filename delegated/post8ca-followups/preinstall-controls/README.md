# Preinstallation evidence controls

These files preserve the first and successor capture and installation scripts,
plus the evidence-scan runner, for review and identity checks. The first scripts
have independently recorded gaps; the successor and later review have their own
qualification. The installer template is uninstantiated and the copies here do
not reproduce the original directory layout or its separately held dependencies.
They are not standalone installation instructions.

The stage scanner, restricted digest corpus, original evidence, Git objects,
key, later logs and restored directory modes remain separately held. These
scripts do not establish independent custody, checkpoint 3821 recovery, audit
closure or product behavior.
