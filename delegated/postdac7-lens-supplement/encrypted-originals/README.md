# Encrypted lens-correction originals

`python3 -B VERIFY.py` checks ciphertext identities. Supplying `--key`
authenticates the private archive; `--restore-root` requires a new path and
restores without overwriting. The separately held same-machine preservation
key is required. Full original q2754 and q2910 replays additionally need their
inner keys and associated Git inputs. This is not independent custody,
product validation, full history recovery, or checkpoint 3821 recovery.
