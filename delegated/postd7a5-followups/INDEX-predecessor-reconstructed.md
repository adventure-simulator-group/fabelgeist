# Evidence navigation for the d7a5 successor

`ASSESSMENT-CENTRAL-FOLLOWUPS-17-95E.json` at the repository root contains
six partial current assessments, two context-only observations and six
planning relationships. `PENDING-DELEGATES.json` preserves the independently
reviewed 20-obligation snapshot. `POSTFREEZE-PENDING.json` adds eight later
source-only obligations whose packets were sealed after that snapshot; these
remain pending central reconciliation.

`SUCCESSOR-CHANGE.json` preserves the initial change note. Its
`SUCCESSOR-CHANGE-v2.json` correction distinguishes parsed-value equality
from raw-byte equality. The original consolidated draft and its predecessors
remain in `central/CENTRAL-EVIDENCE.tar.gz`.

`application/` contains the first exact before/after application and
`application-review/` the independent review of that frozen application.
`application-v2/` is an additive navigation successor: it changes the landing
page to link this index without changing the reviewed queue, ledger, report,
main observation or pending index. The first application's after-image remains
in its archive. The earlier review's `--published` check expects that first
landing-page image; use its archived first-stage inputs when replaying that
review. A separate review of the navigation successor is recorded alongside
it when available.

`package-review/` reviews an earlier five-group frozen snapshot. Dispatch,
the application, the navigation successor and post-freeze packets are outside
that review. `checkpoint-d7a5-recovery/`, `RESTORATION-RECEIPT.json`, and the
three encrypted-original collections record the recovery work and dependencies.
The separately held same-machine primary key, earlier q2812 anchors and named
nested keys remain necessary. Ciphertext is opaque to public scans.

No semantic queue record or lens has been closed. None of these records is
checkpoint 3821, a unique-defect count, product validation or an implemented
repair. Original, reconstructed, historical and newly assessed records retain
the qualifications in their individual packets.
