# Encrypted navigation review originals

Run `python3 -B VERIFY.py` to check ciphertext identities. The separately
held same-machine primary key authenticates the archives; a new restore root
recovers them without overwriting. Earlier anchors and other named inputs
remain separate dependencies.

Ciphertexts are opaque to public scans. This is not independent custody,
complete history, checkpoint 3821 recovery or product validation.
