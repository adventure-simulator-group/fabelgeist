# Encrypted scan review originals

Run `python3 -B VERIFY.py` to verify ciphertext identity. The separately
held same-machine key authenticates the archive and permits restoration to
a new destination. Reconstruct the captured tree from the published files
using the sibling `RESTORE-CAPTURE.py` helper for a full review replay.

This does not establish independent custody, complete privacy, recovery of
checkpoint 3821, audit closure or product behavior.
