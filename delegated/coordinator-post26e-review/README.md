# Coordinator report and metadata review

The registered report displays are exact copies of the clock, readiness,
NPY, NPZ, and blood independent report bytes. They establish report reading
only; the source windows and historical records retain each agent's own
attribution. `UNREGISTERED-NAVIGATION-QUALIFICATION.json` records earlier
report or verifier exposures and their truncated results, without retroactive
credit. The metadata-only registrations, selections, and receipts are retained.

`review/IMPORT-CORRECTION.json` preserves the first private archive import
failure and the later q2303 prefix correction. The initial partial private
import and restricted error transcript remain separately held on this machine.
No product execution or validation is implied.
