# Historical source and registration outputs

These records preserve successful historical command bodies and outputs that
mention the audit workspace and a registration or source object. The runtime
wrapper and local Python startup warning were removed. Filtering is based on
command text: some records are searches, registration inspection or writes,
not source reads. Output may be intentionally sliced or truncated; the flag
captures only known truncation indicators. Inspect commands and dependencies
before relying on any observation. These records are not receipts, current
source qualification, audit credit or the final ledger.

The published batch was screened for common credential, local-path, email and
URL patterns; flagged records were deferred. Command bodies are inert text
and must not be replayed without independent review. Records overlap other
recovery collections.
