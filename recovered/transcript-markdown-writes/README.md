# Historical Markdown write fragments

This corpus preserves 155 literal Markdown writes from successful recorded
commands, with transcript ordinals, historical relative paths, operations,
normalized LF text and SHA-256 hashes. An append record is only a fragment;
the corpus does not establish the complete file, original encoding, later
edits or audit authority. Some text overlaps the separately published notes.
Values were screened for common credentials, personal paths and email
addresses; individual audit claims and dependencies remain unverified.
