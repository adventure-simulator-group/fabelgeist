# Transcript-derived historical records

These historical JSON file versions were reconstructed from file-change
events or printed JSON in a bounded snapshot of the originating chat. Each
file's SHA-256 and corresponding relative path also appear in a recorded
command output. Some references appeared before the printed file, or in the
same output; see the manifest for each provenance. `MANIFEST.json` identifies the source and reference
ordinals, snapshot hash, original paths and recovered byte hashes.

This establishes a match to the historical transcript record, not that the
file was the final version or that its supporting evidence survives. The
records do not restore checkpoint 3821 or authorize audit credit. Review
individual records and dependencies before using them. The raw transcript
remains private; do not execute historical commands or helpers blindly.
