# JSON bodies matched to printed references

These 130 historical JSON bodies were reconstructed from printed output and
match SHA-256 references printed in the historical transcript. The manifest
records the normalized cited path and transcript ordinals for the reference
and body. It does not reproduce the complete original output; path attribution,
current authority, audit credit and dependencies remain unverified. Some
records overlap other historical fragments. Treat proposals and plans as
evidence, not authorization to execute or adopt them.
