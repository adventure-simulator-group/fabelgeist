# Historical draft validation command candidates

These records were selected from draft worktree command executions because
their command text mentions build, test, lint, formatting or acceptance tools.
Selection by text can include commands that only read or edit a test, or
commit its file. Recorded success therefore does not by itself prove a test
ran or passed. Some outputs were redirected, empty, sliced, or truncated;
log files and dependencies may be missing. No current-head, integrated or
product acceptance is claimed.

Recorded status, exit code, command, captured output and transcript ordinal
are preserved. Local paths, URLs and email addresses were redacted. Original
and published text hashes are listed separately. Command bodies are inert
history and must not be replayed without independent review.
