# Late source-related output records

These 57 historical command and output records were selected from the late
checkpoint interval because they mention project source paths, source objects
or registrations and produced substantial output. The runtime wrapper and
local Python startup warning were removed. Some commands are searches or
registration inspection rather than source reads; inspect each before use.
Output can be intentionally sliced even when no truncation flag is set.

The records do not establish a complete registration, receipt, current source
identity, independent audit credit or checkpoint 3821. The command bodies are
inert evidence and must not be replayed without independent review.
