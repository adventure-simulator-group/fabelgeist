# Historical queue-related command outputs

These records preserve successful historical command bodies and outputs that
mention a closure queue, keyed by transcript ordinal. Command context does not
prove every printed value came from a queue. The runtime wrapper and local
Python startup warning were removed, and machine-specific paths were redacted.
Hashes cover the original and published text separately. Some outputs were
truncated or intentionally sliced; `possible_output_truncation` flags only
known indicators. The collection overlaps other recovered evidence.

These are historical observations, not the latest queue or proof of audit
closure. Commands are inert text: do not replay them without independently
recovering their inputs and reviewing their effects.
