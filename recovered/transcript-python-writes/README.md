# Historical Python literal writes

These 310 records preserve literal text from successful recorded Python file
writes, including historical acceptance drafts. Each has a command ordinal,
relative path and hash of normalized LF text. Five contain redacted local
paths; their original normalized hashes identify the private text. Original
file bytes, later changes, dependency state, validation and current relevance
are not established. The texts are inert evidence: do not execute them without
independent review. No draft is claimed to have passed acceptance testing.
