# Historical audit write command candidates

These are 5,342 successful historical command bodies selected because they
mention the deleted audit workspace and file-write operations. The original
runtime wrapper is omitted. A separate 281 reviewed records are preserved in `REVIEWED-COMMANDS.jsonl`;
265 have machine-specific paths redacted. Public URLs and the generic no-reply
email were checked. Original hashes identify private, unredacted versions.
Screening does not prove that the commands are safe.

The bodies are inert evidence, not recovered file outputs. Their timestamps,
input state, dependencies and latest effects are generally unknown. Do not
replay them without an independently restored base and individual review.
Many overlap the late-command and literal-write collections.
