# Alternate-field source identities

These 15 identities were recorded in complete JSON row fragments using
alternate path or hash field names. Each matches its pinned Git bytes. The
list may overlap other recovery collections and does not establish read
attribution, audit credit or final authority.

Run `python restore_sources.py REPOSITORY DESTINATION` from this directory.
The destination must not exist, each hash is checked, and an incomplete
marker remains if restoration fails. Binary assets are restored byte-for-byte.
