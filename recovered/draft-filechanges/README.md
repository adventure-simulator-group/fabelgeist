# Historical implementation draft changes

These 287 historical file-change records span seven isolated draft
worktrees. `MANIFEST.json` maps each worktree to its pinned published branch,
last recorded file change and last recorded successful push. Every recorded
file change in this set preceded its branch's recorded push. That does not
prove all shell writes or working-tree state were captured or published.

`RECORDS.jsonl` preserves patch, add and delete text with per-record hashes.
These records are historical, incomplete and inert. Do not apply them without
independently establishing the correct base and reviewing dependencies. The
published draft commits and their validation limitations remain listed in
`../../SOURCE-LOCATORS.json`; no integrated acceptance or repair completion
is claimed.
