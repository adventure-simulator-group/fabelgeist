# Historical audit helper candidates

This file contains Python helper candidates reconstructed from recorded
file-change additions and strict-context patches. Each JSONL record preserves
its historical relative path, change ordinals and candidate byte hash. These
are inert text, not tools to run. The original bytes, subsequent shell writes,
latest versions, dependencies, safety and audit authority are unverified.
Do not execute or adopt them without independent review.

The batch was screened for common credentials, personal paths and email
addresses. Candidates containing personal-path or email patterns remain private pending
further review. Public URL references were inspected before inclusion. These candidates overlap other
recovered records and do not restore the final ledger.
