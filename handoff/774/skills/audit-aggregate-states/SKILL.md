# Aggregate states

Inventory affected records and meaningful collections, then trace how each
relationship is established, retained, mutated and consumed.

- Check ordered bounds, positive divisors, matching column lengths/order,
  parent/index membership, periodic seams and correlated lifecycle data.
- Construct an invalid combination from otherwise valid leaves. Inspect public
  fields, independent setters, deserialization and mutation after validation.
- Check whether the complete record is admitted atomically and whether its
  exposed operations preserve the relationship.
- Use controlled construction, private storage or payload-bearing states where
  they close the actual gap. Do not impose elaborate branding without need.

Name the relationship and the consumer that relies on it. Separate an actual
bad construction path from a representable API weakness. Enum-shape changes
may be a remedy, but this lens must inspect non-enum aggregates too.

Pin scope/revision; read applicable rules. Before repairs, finish this lens's
exhaustive pass and write an ignored ledger: source locations, contracts/traces,
dispositions, exact connected repairs and acceptance criteria. Account for every
scoped path; group only identical justifications. Untraced paths remain incomplete.
Review only unless fixes/publication are authorized. Distinguish defects,
migration gaps and suggestions.
