# Magic strings

Every raw string is magic, including prose, paths, format tokens and fixture data.

- Inventory literals, fields, parameters, returns, constants, defaults and
  extracted text across code, configuration, attributes, macros and embedded code.
- Trace each occurrence to its semantic owner or concrete text boundary. Carry
  existing identifiers, enums or bespoke text types through application APIs;
  admit or classify raw text at its actual source.
- Keep open identifiers open. Preserve wire shapes and accepted inputs.
  Constants, private helpers, catalogs and fixtures are not blanket exemptions.

Pin scope/revision; read applicable rules. Before repairs, finish this lens's
exhaustive pass and write an ignored ledger: source locations, contracts/traces,
dispositions, exact connected repairs and acceptance criteria. Account for every
scoped path; group only identical justifications. Untraced paths remain incomplete.
Review only unless fixes/publication are authorized. Distinguish defects,
migration gaps and suggestions.
