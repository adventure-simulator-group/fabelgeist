# Proposed audit scope for completing PR #774

This is a proposal awaiting Adler's decision. It does not change the current
handoff requirements or authorize implementation before the existing gate.

The original gate has expanded to 2,798 source variants, with 226 additional
bounded roles. The ongoing initial inventories remain incomplete. No source
repairs, builds, tests, generators or hosted validation have run in this
continuation. Existing unrelated GPU changes remain separate.

## Keep the implementation objective

Complete all twenty migration families, including mandatory P16 and P17 and the
six reopened families. Recover coherent function changes from the preserved
snapshots into the current PR contracts. Preserve tactical state authority,
deterministic draw order, valid zero/negative quantities, distinct coordinate
frames, historical evidence, and meaningful absence or impossibility.

Carry canonical bespoke types through producers, retained state, operations and
consumers. Extract primitives at actual format, storage, framework or numerical
operations. A private helper does not justify extraction. Remove compatibility
paths encountered in this work. Broad changes remain authorized when this is
the clean final design.

## Proposed initial audit boundary

Account for the contracts changed by those migrations and every producer,
retained representation, operation and recipient necessary to assess them.
Read dependency code where it establishes the actual native boundary. Do not
turn that read into a general audit or ownership rewrite of the dependency.

Keep demonstrated migration defects and failures of affected guarantees in the
repair plan. Preserve separate evidence for preexisting unrelated API hardening
and dependency observations; defer those unless the final implementation changes
or relies on the relevant contract. No current defect is inferred solely from a
hypothetical edited asset, extreme input, missing fixture, or source comment.

Examples of connected repairs already supported by source evidence:

- P16 physical geometry, mass, cadence, selected combat equipment and targeting
  policy must propagate through authored content, evaluated inventory, player
  admission, Core, tactical server and actual client consumers. Preserve distinct
  human/nonhuman and biological/equipped mass policies.
- P17 observations must retain the original sample tick, canonical foot identity,
  optional motor evidence and measurements through report computations. Absence
  must not become a zero measurement or successful empty report. Preserve typed
  callback failure through native observers and retained report readback.
- Rig topology, packed skin membership, catalogue placement handles and garment
  offsets must retain the existing canonical owners across Creator, runtime and
  rendering. Compose shared prepared products without recomputing cached physical
  properties or discarding existing reservation/revision behavior.
- Strategic operations must preserve original concrete error causes to the real
  reducer boundary. Shared value owners and checked state must survive database
  and Web adapters; rights decisions and cached projections must remain bound to
  the correct actor, request and authoritative input revision.
- Battle attack identity currently discards the upper 32 bits of supported actor
  IDs. Preserve a full attack identity through scheduling, phase state, batches,
  timeline and report consumers instead of wrapping the lossy calculation.
- The opposed movement kernel can mask a finite arithmetic overflow with clipping
  and return inconsistent distance/displacement evidence. Check computed native
  results before clipping; ordinary structured overflow rejection is valid.

## Keep final acceptance

Run all thirteen audits on the completed connected change, reconcile findings
and repeat affected work until clear. Obtain independent Code, Rule and Comment
reviews. Adapt existing tests only, preserving their inputs, order and oracle
intent. Use the required hosted validation matrix and revision/artifact guards
on one final pushed PR head. Do not merge the PR or declare epic #726 complete.

The alternative is to retain the original exhaustive initial inventory over the
entire expanded scope before any implementation. Until Adler chooses otherwise,
that original requirement remains in force.
