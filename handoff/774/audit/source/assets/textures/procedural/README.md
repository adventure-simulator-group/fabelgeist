# Baked procedural textures

The `.ptex` files in this directory are committed runtime assets, like the body
mesh. Tactical startup loads them asynchronously through Bevy's asset server;
it does not run the texture generators or silently regenerate missing files.
No environment variable or first-run bake is required.

After changing a recipe in `crates/adventuresim-procedural-textures`, explicitly
rebuild its asset from the repository root:

```text
just bake-procedural-textures oak-bark
```

Rebuild the complete collection with `just bake-procedural-textures`. Review and
commit the resulting assets alongside the recipe changes. This command uses
the default deterministic parameters at full resolution and verifies a
lossless round trip before writing each file. It is not a build or init hook.

Each file is a gzip-compressed recipe bake: a length-prefixed JSON header and
the original pixel payloads, including every authored mip level, color-space
encoding, and sampler descriptor. Compression is lossless; normal maps,
coverage-preserving leaf mips, and packed channels are not regenerated by the
loader. The runtime terrain blood mask is separate, empty per session, and
never stored here.

Use `cargo test -p adventuresim-procedural-textures` to check the codec and
load the committed collection through the actual asset loader. The texture
studio and `procedural-texture-lab` remain the recipe-authoring/review tools;
their review exports are not substitutes for these runtime assets.
