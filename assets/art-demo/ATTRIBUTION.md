# Museum reference photographs

The two photographs accompany the existing museum assemblies from
`codex/museum-armor-sets` ([PR #653](https://github.com/adventure-simulator-group/fabelgeist/pull/653)).
The Met identifies both photographs as public domain. The local copies were
reused from that branch's museum reference collection; records verified
2026-09-14.

| File | Collection and object |
| --- | --- |
| `references/henry.jpg` | [The Met, Henry VIII's field armor, 32.130.7a–l](https://www.metmuseum.org/art/collection/search/23936) |
| `references/nuremberg.jpg` | [The Met, Nuremberg field armor, 04.3.289](https://www.metmuseum.org/art/collection/search/22001) |

[Met Open Access](https://www.metmuseum.org/about-the-met/policies-and-documents/open-access)
provides public-domain collection images under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The procedural assemblies interpret the displayed suits. Henry's engraving and
soft-material wrinkles are not reproduced. The Nuremberg display combines
parts from several armors and includes later replacements, as its record notes.
